# 🌊 Neon Aquarium Portfolio — Redwan (Its-Rafin)

A stunning 3D interactive portfolio built with **Three.js**, **TailwindCSS**, and **Vite**.

## ✨ Features

- 🐠 **Procedural 3D Bioluminescent Fish** — Full-screen animated fish swimming across a dark aquatic background using Three.js with spine-wiggle physics
- 🎮 **3D Project Cards** — Each project card has its own live WebGL scene (neural network, matrix rain, blockchain cubes) rendered via individual per-card canvas elements
- 💻 **Boot Terminal Loading Screen** — Cyberpunk-style terminal boot sequence on page load
- 🔄 **Scroll Reveal Animations** — Smooth AOS-like reveal animations triggered by IntersectionObserver
- 📊 **GitHub Contribution Graph** — Dynamically generated heatmap-style contribution grid
- 📬 **Contact Form** — Simulated packet-send terminal experience

## 🛠️ Tech Stack

- [Three.js](https://threejs.org/) — 3D WebGL rendering
- [TailwindCSS](https://tailwindcss.com/) — Utility-first CSS
- [Vite](https://vitejs.dev/) — Lightning-fast dev server & bundler
- Vanilla JavaScript (ES Modules)

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 📦 Build for Production

```bash
npm run build
```

Output goes to `dist/` — ready for GitHub Pages, Netlify, or Vercel.
